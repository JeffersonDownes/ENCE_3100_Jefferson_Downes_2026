# ENCE_3100_Jefferson_Downes_2026

A collection of my coursework, Verilog designs, and FPGA projects for **Advanced Digital System Design (ENCE-3100)** at the **University of Denver**.

## Hardware and Software

* **FPGA board:** Terasic DE10-Lite
* **FPGA device:** Intel MAX 10 — 10M50DAF484C7G
* **Development software:** Quartus
* **Hardware description language:** Verilog HDL

## Using the Designs

1. Create a Quartus project targeting the **10M50DAF484C7G**.
2. Add the Verilog files required for the selected exercise.
3. Set the appropriate top-level module and apply the DE10-Lite pin assignments.
4. Compile and program the FPGA.
5. Test the circuit using the board’s switches, LEDs, and displays.

Each exercise may use different switch mappings and module dependencies. Refer to its source code and accompanying notes before programming the board.

This repository documents my progress in digital logic design and implementing circuits on FPGA hardware.
